# Leonida artwork

- `wordmark-<region>.png` — the region's logo, shown instead of its name in Gameplay › Leonida.
- `postcard-<region>.jpg` — shown when you hover the region (16:9).
- `logo-<region>.png` — Rockstar's original overlay the wordmark was cut from.

Region names in lower case with dashes, e.g. `hamlet`, `watson-bay`.
